Precios al Día

Aplicación de ofertas diarias de productos de la canasta básica en México.

Objetivo

Encontrar, comparar y consultar ofertas de productos en diferentes establecimientos.

Funciones

- Consulta de productos en oferta.
- Comparación de precios.
- Descuentos y ahorro.
- Carrito de compras.
- Productos organizados por establecimientos y categorías.

Instalación

Aplicación web progresiva (PWA).
